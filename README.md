## ✦ &nbsp;The Story

I started out designing things that fly.

Aerospace engineering teaches you to think in systems — every component has a function, every failure has a root cause, and precision is not optional. What it doesn't teach you is that the most interesting systems aren't mechanical. They're organisational. They're made of people, incentives, processes, and — crucially — **data that nobody is reading correctly**.

That realisation took me from BMS College to **KPMG**, where I spent three years embedded in Fortune 500 operations. Building ETL pipelines that didn't break. Validation frameworks that caught what humans missed. Executive dashboards that 20+ leaders opened every morning because the data actually answered their questions. Two company-wide awards. Over a million dollars in identified savings. The engineering mindset, applied to business.

Now I'm at **Tufts**, earning my MEM and building in public everything I always wanted to ship but never had time to. The repos below are real work — not tutorials, not toy datasets.

> *I don't make dashboards. I answer questions with data, and the dashboard is just the receipt.*

```
powerbi-dashboard/ → packaged .pbix + screenshots
insight-memo.pdf   → the one-pager that drives the room
```

### &nbsp;[`data-validation-engine`](https://github.com/IshtarthUmesh/data-validation-engine)

<div>

![Status](https://img.shields.io/badge/%E2%97%8F%20Live-22c55e?style=flat-square)

![License](https://img.shields.io/badge/MIT-f59e0b?style=flat-square)
![Contributions Welcome](https://img.shields.io/badge/Contributions-Welcome-7c3aed?style=flat-square)

</div>

The tool that won me KPMG's Rising Star Award — rebuilt clean and open-sourced. Point it at any CSV: it validates structure, flags anomalies, checks ranges and types, and generates a **stakeholder-ready Excel report** in one call. Designed so that the person reading the output doesn't need to understand the code that produced it.
```python
from validator import DataValidator

dv = DataValidator("your_data.csv")
dv.validate(
    required_columns=["order_id", "customer_id", "amount"],
    date_columns=["created_at"],
    numeric_ranges={"amount": (0, 1_000_000)},
    unique_columns=["order_id"]
)
dv.export_report("validation_report.xlsx")
# → Excel workbook: summary tab + flagged rows + error distribution chart
```

## ✦ &nbsp;How I work

Skipping steps is how you end up with a beautiful dashboard that nobody uses. Every engagement I run follows this sequence — not as a template, but because the sequence exists for a reason.
```
  DISCOVER      DEFINE        MAP          BUILD       VALIDATE    VISUALISE     DELIVER
     │             │            │             │            │            │            │
 👂 JTBD       📝 BRD        🗺  BPMN      🔧 SQL      ✅ UAT      📊 Power BI   💡 Memo
 interviews    FRD · user    process       Python       QA          Tableau       that
 stakeholder   stories       flows         ETL          testing     dashboards    drives a
 sessions      acceptance    swimlanes     pipelines    sign-off    reports       decision
                criteria

                                  └──────────────── 🔄 repeat ─────────────────┘
```
